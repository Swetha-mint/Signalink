01 / WHY SIGNALINK

Communication should not be limited by the interface.

SIGNALINK is an open-source engineering initiative for building practical communication technologies. Sign-language communication is one starting application within a broader mission: using engineering to create useful systems for communities whose communication and accessibility needs are often overlooked.

We learn by building — from sensors and digital logic to intelligent edge systems — and publish the work so others can inspect, reproduce, and improve it.
